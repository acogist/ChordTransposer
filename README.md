# Chord Transposer

コード進行を転調するシングルファイルのWebアプリ（HTML/CSS/JSのみ・ビルド不要）。

## 使い方
`index.html` をブラウザで開くだけで動作します。

## 公開（GitHub Pages）
Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)`

公開URL: `https://<ユーザー名>.github.io/<リポジトリ名>/`

## 開発
`index.html` を編集して commit / push するだけ。Pagesに自動反映されます。
